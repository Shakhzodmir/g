# Gapimiz

Приложение для общения и развития речи для детей и взрослых с аутизмом и другими нарушениями речи. Сделано в первую очередь для Узбекистана и стран СНГ.
Nutqida qiyinchiligi bor bolalar va kattalar uchun muloqot va oʻyin ilovasi.

**Открыть:** https://shakhzodmir.github.io/g/ (ставится на телефон, ПК и интерактивную доску как приложение; после первого открытия работает без интернета)

## Что внутри
- **Говорить (AAC):** карточки с озвучкой на узбекском (латиница и кириллица) и русском. Ядро 6×6 на фиксированных местах, темы, своя запись голоса, свои фото, режим «показываю», клавиатура и шкала боли для взрослых.
- **Мой день, таймер, звёздочки:** визуальные опоры для предсказуемости.
- **Уголок спокойствия и «Перерыв»:** кнопка всегда на месте, дыхание без звука по умолчанию.
- **Мои чувства и социальные истории.**
- **Игры и разминка:** без проигрыша, без таймеров; микрофон и камера необязательны, всё остаётся на устройстве.
- **Режим доски:** крупно и в зоне досягаемости детей; панель педагога.
- **Раздел для взрослых:** прогресс без оценок, редактор карточек, профили, настройки, копия данных, печать карточек.

## Принципы
Спокойно по умолчанию, ничего не мигает и не звучит неожиданно, нет рейтингов и серий дней, ошибки не наказываются. Данные хранятся только на устройстве.

## Разработка
```bash
npm install
npm run dev          # http://localhost:5173
npm run typecheck && npm test
npm run build        # dist/
npx playwright test  # e2e (нужен предварительный npm run build)
node e2e/audit.mjs http://localhost:5173/   # аудит текстов и отступов
```
Стек: Vite, React 19, TypeScript, PWA (Workbox), Dexie, Motion. Подробности: `docs/`.

- `docs/superpowers/specs/` — спецификация продукта
- `docs/superpowers/plans/` — план реализации
- `docs/research/research-report.md` — исследование (конкуренты, доказательная база, технологии, Узбекистан, бизнес)
- `docs/content-review-v0.1.md` — что должен проверить носитель языка и логопед до пилота
- `scripts/README.md` — как пересоздать озвучку и символы

## Лицензии
Символы: Microsoft Fluent Emoji (MIT). Озвучка: Silero (MIT), временная, к пилоту заменяется записью диктора. Шрифты Nunito и Onest: SIL OFL 1.1. Подробнее в разделе «О приложении».
