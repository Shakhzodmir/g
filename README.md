# Приложение для развития речи и общения (Узбекистан)

> Рабочее название выбирается. Репозиторий будет переименован, когда название утвердим.

Приложение для детей и взрослых, которым трудно говорить: аутизм, алалия, дизартрия, апраксия, ДЦП,
синдром Дауна, нарушения слуха, афазия после инсульта. Оно помогает общаться через карточки с озвучкой (AAC),
а играть и учиться можно вместе с родителями и специалистами.

- Языки: oʻzbekcha (lotin), ўзбекча (кирилл), русский
- Устройства: телефон, планшет, ПК, интерактивная доска (один адрес, устанавливается как PWA)
- Работает офлайн, данные хранятся только на устройстве
